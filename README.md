# Desarrollo de Aplicaciones Web

Proyecto integrador desarrollado de manera progresiva para la asignatura Desarrollo de Aplicaciones Web. El sitio evidencia el uso de HTML5, CSS3, Bootstrap, JavaScript, validaciones dinámicas, contenido renderizado desde datos, estructura reutilizable y mejora visual de interfaces.

## Historial de avances

### Semana 3: Estructura HTML5 y contenido semántico
Se construyó la estructura principal del sitio mediante etiquetas semánticas como header, nav, main, section, article, aside y footer. La página integró secciones de inicio, quiénes somos, servicios, contacto, una imagen relacionada, video mediante iframe y contenido complementario.

### Semana 4: CSS3, Bootstrap y diseño responsivo
Se mejoró la apariencia del sitio mediante estilos CSS3 y componentes de Bootstrap. Se incorporaron colores, tarjetas, botones, formulario de contacto, imágenes responsivas, menú de navegación y distribución adaptable para computadora, tablet y celular.

### Semana 5: JavaScript e interacción básica
Se añadieron funciones con JavaScript para fortalecer la interacción del usuario con la página. El sitio incorporó acciones dinámicas, manejo básico de eventos y presentación de información en pantalla.

### Semana 6: Validaciones dinámicas y manejo de formularios
Se actualizó el formulario principal para validar datos en tiempo real mediante JavaScript. Se aplicaron eventos input, blur y submit, uso de preventDefault(), mensajes de error y éxito, clases visuales de Bootstrap, registro dinámico de solicitudes, conteo y eliminación de registros sin recargar la página.

### Semana 7: Plantillas y contenido dinámico
Se reorganizó la interfaz simulando una estructura de plantillas reutilizables. Se identificaron bloques como encabezado, navegación, contenido principal y pie de página. JavaScript renderiza rutas y estructura del sitio desde arreglos de objetos, evitando repetir manualmente bloques HTML innecesarios.

### Semana 8: Mejora de interfaces con Bootstrap y JavaScript
Se modernizó la interfaz usando Bootstrap y JavaScript. El proyecto conserva su enfoque educativo y utiliza menú responsivo, sistema de grilla, tarjetas, formularios, botones, alertas, modal y spinner para mejorar la navegación, la lectura, la retroalimentación visual y el registro dinámico de información.

## Funcionalidades principales

- Menú de navegación responsivo con Bootstrap.
- Secciones organizadas mediante sistema de grilla.
- Rutas de aprendizaje generadas dinámicamente desde JavaScript.
- Componentes Bootstrap renderizados en tarjetas.
- Estructura reutilizable del sitio simulada para futura integración.
- Formulario con validaciones dinámicas, mensajes de error y éxito.
- Registro, conteo, detalle en modal y eliminación de solicitudes.
- Spinner Bootstrap para simular procesos de carga.
- Contacto con formulario, correo, redes, GitHub, sitio publicado y ubicación.
- Diseño adaptable para computadora, tablet y celular.
