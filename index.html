Quiénes somos

Una guía clara para perderle el miedo al código

DAW UEA se presenta como una propuesta educativa para acompañar a personas que desean comprender cómo funciona una página web y reforzar sus bases en desarrollo del lado del cliente. La idea es explicar cada parte del proceso con un lenguaje claro, ejemplos visibles y actividades pequeñas que permitan avanzar con seguridad frente a etiquetas, estilos, componentes responsivos y scripts.

El sitio organiza el aprendizaje en rutas prácticas: primero se reconoce la estructura de una página con HTML5, luego se mejora la apariencia con CSS3, después se adapta el diseño con Bootstrap y, más adelante, se incorporan validaciones con JavaScript para que los formularios respondan de manera inteligente. Así, cada visitante puede mirar, probar y registrar su interés en la ruta que necesita reforzar.

Rutas de aprendizaje

Aprende por partes, aplica desde el primer día

Las rutas están organizadas para que el aprendizaje no se quede en teoría. Cada tema se relaciona con una acción concreta dentro de una página web real.

HTML

Estructura de la página

Reconocer encabezados, menús, secciones, artículos, formularios y pie de página para ordenar correctamente el contenido.

CSS

Diseño visual

Aplicar colores, tipografías, márgenes, sombras y efectos básicos para que la página sea más clara y agradable.

BS

Diseño responsivo

Usar contenedores, filas, columnas, botones y tarjetas de Bootstrap para adaptar el sitio a computadora, tablet y celular.

JS

Interacción y validación

Validar campos en tiempo real, mostrar mensajes, registrar datos en pantalla y evitar errores antes de enviar formularios.

Método práctico

Antes de diseñar, entiende qué debe resolver la página

Una página educativa funciona mejor cuando responde preguntas reales: qué aprenderá la persona, por dónde debe empezar, qué recurso le conviene y cómo puede pedir orientación. Por eso este sitio combina contenido explicativo con un formulario que clasifica intereses y muestra registros sin recargar la página.

1. Ruta visible El usuario entiende qué tema escoger sin leer instrucciones largas.
2. Mensajes claros Los errores aparecen cerca del campo para corregirlos rápido.
3. Validación inmediata JavaScript revisa los datos mientras la persona escribe.
4. Registro dinámico La solicitud se muestra en pantalla sin actualizar el navegador.
