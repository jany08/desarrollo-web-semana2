Quiénes Somos

Este proyecto académico ha sido desarrollado como parte de la asignatura Desarrollo de Aplicaciones Web. Su objetivo es aplicar conocimientos de HTML5, CSS3 y Bootstrap para crear sitios web modernos, accesibles y responsivos. La plataforma permite demostrar el uso de estructuras semánticas, diseño adaptable y recursos multimedia para mejorar la experiencia del usuario y fortalecer las competencias tecnológicas.
