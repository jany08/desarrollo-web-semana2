Quiénes somos

Una guía clara para perderle el miedo al código

DAW UEA se presenta como una propuesta educativa para acompañar a personas que desean comprender cómo funciona una página web y reforzar sus bases en desarrollo del lado del cliente. La idea es explicar cada parte del proceso con un lenguaje claro, ejemplos visibles y actividades pequeñas que permitan avanzar con seguridad frente a etiquetas, estilos, componentes responsivos y scripts.

El sitio organiza el aprendizaje en rutas prácticas: primero se reconoce la estructura de una página con HTML5, luego se mejora la apariencia con CSS3, después se adapta el diseño con Bootstrap y, más adelante, se incorporan validaciones con JavaScript para que los formularios respondan de manera inteligente.

Bootstrap + JavaScript

Herramientas visuales para construir una página moderna

La página integra recursos visuales que ayudan a comprender cómo se organiza una interfaz web moderna. El menú permite recorrer las secciones principales, las tarjetas presentan contenidos de forma ordenada, las alertas muestran respuestas inmediatas al usuario y el formulario valida la información antes de registrar una solicitud.

Con estos elementos, el sitio demuestra cómo Bootstrap mejora la presentación y cómo JavaScript aporta interacción sin recargar la página.

Estructura reutilizable

Estructura del sitio web

El sitio se organiza en bloques reutilizables para mantener una estructura clara y fácil de actualizar. El encabezado, el menú, el contenido principal y el pie de página se tratan como partes independientes, de modo que puedan adaptarse a una plantilla base cuando el proyecto avance hacia Flask.

Las tarjetas de esta sección se generan con JavaScript a partir de objetos, lo que permite representar contenido dinámico sin escribir manualmente el mismo bloque HTML varias veces.

Método práctico

Antes de diseñar, entiende qué debe resolver la página

Una página educativa funciona mejor cuando responde preguntas reales: qué aprenderá la persona, por dónde debe empezar, qué recurso le conviene y cómo puede pedir orientación. Por eso este sitio combina contenido explicativo con formularios que clasifican intereses y muestran solicitudes sin actualizar el navegador.

1. Ruta visible El usuario entiende qué tema escoger sin leer instrucciones largas.
2. Mensajes claros Los errores aparecen cerca del campo para corregirlos rápido.
3. Validación inmediata JavaScript revisa los datos mientras la persona escribe.
4. Registro dinámico La solicitud se muestra en pantalla sin actualizar el navegador.
