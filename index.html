Quiénes somos

Una guía clara para aprender construyendo

DAW UEA es una propuesta educativa orientada a explicar cómo se construye una página web desde su estructura visual hasta su organización como aplicación. El sitio presenta contenidos breves, rutas de aprendizaje y ejemplos funcionales para que el usuario comprenda el uso de etiquetas HTML, estilos CSS, componentes Bootstrap, validaciones con JavaScript y plantillas preparadas para Flask.

La página conserva una presentación ordenada y responsiva, incorpora interacción mediante JavaScript y organiza sus recursos en una estructura pensada para futuras vistas internas. De esta manera, el proyecto mantiene su enfoque educativo y avanza hacia una aplicación web más completa, sin perder claridad para quienes están iniciando en el desarrollo del lado del cliente.

Rutas del proyecto

Módulos educativos preparados para Flask

La versión Flask del repositorio organiza el contenido en rutas relacionadas con el aprendizaje web, la participación de usuarios, los recursos digitales y las solicitudes de orientación.

Flask + Jinja2

Organización interna del sitio educativo

El repositorio incluye una base Flask con rutas principales, una carpeta de plantillas y recursos estáticos separados. La página visual publicada en GitHub Pages se conserva como frontend, mientras que el código Flask queda listo para ejecutarse de forma local y revisar la organización del proyecto.

El proyecto conserva una versión visual publicada en GitHub Pages y, al mismo tiempo, incorpora una estructura inicial en Flask para organizar mejor las rutas, las plantillas y los recursos del sitio.
Recurso multimedia

Video de apoyo para reforzar el aprendizaje

El recurso multimedia complementa la explicación del proyecto porque permite relacionar la teoría con la práctica. En una página educativa, el video ayuda a reforzar procesos como estructura HTML, organización visual, navegación y uso de herramientas web.
