Inicio

Bienvenido a este sitio web académico dedicado al estudio del desarrollo de aplicaciones web. Aquí se presentan conceptos básicos relacionados con HTML5, CSS3 y JavaScript, tecnologías fundamentales para la creación de sitios web modernos y dinámicos.

Quiénes Somos

Este proyecto académico ha sido desarrollado como parte de la asignatura Desarrollo de Aplicaciones Web. Su objetivo es aplicar los conocimientos adquiridos sobre HTML5 y la estructura semántica de los documentos web. A través de este sitio se busca demostrar el uso correcto de etiquetas básicas, la organización adecuada del contenido y la navegación interna. Además, permite comprender la importancia de las buenas prácticas en el diseño y desarrollo de páginas web. La plataforma está orientada al aprendizaje de tecnologías web modernas y constituye una base para futuros proyectos relacionados con el desarrollo de aplicaciones en Internet. También fomenta el uso de recursos multimedia y la correcta estructuración de la información para mejorar la experiencia de los usuarios y fortalecer las competencias tecnológicas de los estudiantes.

Servicios

  • Diseño web con CSS3
