Quiénes Somos

Este sitio web académico ha sido desarrollado como una propuesta práctica de la asignatura Desarrollo de Aplicaciones Web, con el propósito de aplicar conocimientos de HTML5, CSS3 y Bootstrap en una página funcional, ordenada y adaptable. La estructura integra encabezado, menú de navegación, contenido principal, secciones informativas, recursos multimedia, formulario de contacto y pie de página, lo que permite presentar la información de manera comprensible y visualmente agradable.

La página está pensada como un espacio demostrativo para organizar contenidos digitales con criterio técnico y diseño claro. Por ello, se emplean etiquetas semánticas que facilitan la lectura del navegador, componentes responsivos para mejorar la visualización en diferentes pantallas y elementos gráficos que ayudan al usuario a identificar rápidamente cada parte del sitio. Esta combinación permite fortalecer competencias básicas para construir páginas web modernas, accesibles y coherentes con las necesidades actuales de comunicación digital.

Ideas útiles para mejorar una página web

Una página web no se mejora llenándola de elementos al azar, sino tomando decisiones pequeñas que hacen que el usuario entienda rápido dónde está, qué puede hacer y cómo puede moverse dentro del sitio. Estas ideas sirven para aplicar diseño web con más intención y menos improvisación.

Ruta sencilla para construir mejor

  • Definir primero las secciones importantes: inicio, presentación, servicios y contacto.
  • Usar un menú corto con nombres claros para que la navegación sea directa.
  • Colocar imágenes que expliquen el tema, no imágenes decorativas sin relación.
  • Probar la página reduciendo la ventana del navegador para revisar el diseño responsivo.
01

Jerarquía visual

El título principal debe verse primero, luego el texto de apoyo y después los botones. Así el usuario no se pierde entre demasiada información.

02

Tarjetas con sentido

Cada tarjeta debe explicar una sola idea. Un título, una breve descripción y un botón son suficientes para mantener orden y claridad.

03

Formulario entendible

Los campos deben tener etiquetas claras, espacios adecuados y un botón visible. Esto mejora la confianza y facilita la interacción.

04

Pantallas pequeñas

En celular, los textos deben seguir siendo legibles, las imágenes no deben salirse del ancho y los botones deben poder tocarse con facilidad.

Cómo se aplica en este sitio

La página usa una estructura por bloques para que el contenido no aparezca acumulado. El encabezado presenta la idea central, las tarjetas resumen los componentes del proyecto, la sección multimedia refuerza el aprendizaje y el formulario simula una interacción básica con el usuario. Con Bootstrap, las columnas se reorganizan automáticamente en pantallas pequeñas, mientras que el CSS personalizado aporta identidad visual mediante colores, sombras, bordes y espaciados.

También se incorporan botones con acciones claras, imágenes adaptables mediante la clase img-fluid y una media query que ajusta altura del video, espaciados y alineación cuando la pantalla es más pequeña.

Recurso multimedia

El video seleccionado complementa el tema porque muestra el uso de Bootstrap en la construcción de una barra de navegación responsiva, un elemento necesario para que el sitio pueda adaptarse a diferentes pantallas y conservar una navegación clara.
